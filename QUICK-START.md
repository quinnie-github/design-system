# 🚀 Quick Start: Design System Generator

## ⚡ Install & Run in 2 Minutes

### Step 1: Install (30 seconds)
```
1. Open Figma
2. Plugins → Development → Import plugin from manifest...
3. Select:
   /Users/quinniechen/Downloads/figma-variable-updater/
   figma-plugin/design-system-generator/manifest.json
4. Done!
```

### Step 2: Test (1 minute)
```
1. Create 3 frames in Figma:
   - Rectangle with blue fill (#2563eb)
   - Rounded rectangle + text ("Button")
   - Frame with border

2. Select all 3 frames

3. Run: Plugins → Design System Generator

4. Click "Analyze Design"

5. See detected colors and components!

6. Click "Generate System"

7. New page created with design system ✨
```
