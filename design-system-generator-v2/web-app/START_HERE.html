🎨 Design System Generator v2.0

Quick Start Guide

⚠️ Important: The proxy server MUST be running for this to work!
Step 1: Start Proxy Server
Open terminal and run:
cd design-system-generator-v2/proxy-server && npm start
Step 2: Open the Web App
Double-click this file in your file manager:
design-system-generator-v2/web-app/index.html

Or just click here: Open Web App
Step 3: Get Your API Key
Visit: console.anthropic.com
Copy your Claude API key (starts with sk-ant-api03-...)
Step 4: Analyze a Design
1. Enter your API key in the web app
2. Upload a design screenshot
3. Click "Analyze Design"
4. Download the JSON file
Step 5: Import to Figma
1. Open Figma
2. Run the Design System Generator v2.0 plugin
3. Import your JSON file
4. Generate your design system!

🐛 Troubleshooting

  • Proxy server not running? You'll see connection errors. Start it with npm start
  • CORS errors? Make sure proxy URL is http://localhost:3002
  • API key issues? Get a fresh key from console.anthropic.com
